# Is Whitman Rowing Today?

Static site for https://iswhitmanrowingtoday.com, hosted on Netlify. No build step: Netlify publishes this folder as-is.

| Path | What it is |
|---|---|
| `index.html` | Today/Tomorrow practice status, driven by the "Is Whitman Rowing Today Website" Google Sheet |
| `nest-logger/index.html` | Separate unlisted, no-index page for the Nest temperature logger project |
| `_redirects` | Sends the old `/weather` and `/weather2-test` links to the weather site, https://dcrowingweather.netlify.app (repo `dpnoyes1/dcrowingweather`) |
